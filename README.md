# Viewer control and contextual relevance in AVOD advertising: data and analysis code

This repository reproduces every number, table and figure in the paper (Experiment 1) from the
de-identified export of the experimental platform. The pre-registration, with item wordings, the
power analysis and the full analysis plan, is at https://osf.io/sjrgf/overview?view_only=183d07bed7c24c7ca0266617fea20c3c (view-only link).

## Reproduce the results

Requires Python 3.12.

```
python3.12 -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter nbconvert --to notebook --execute --inplace analysis.ipynb
```

This runs the whole analysis, rewrites the outputs in `analysis.ipynb` and regenerates the three
figures in `figures/`. To work through it interactively instead, run `jupyter notebook analysis.ipynb`
and choose Run All.

The structural equation model's bootstrap (5,000 resamples) takes about five minutes; everything
else takes seconds. All random seeds are fixed, so every run gives identical results.
`requirements.txt` pins the packages the analysis uses; `requirements-lock.txt` pins the complete
environment the results were verified with, if you need an exact match.

## Data

Each row is one session on the platform. `condition` is the ad timing (A0 post-roll, A1 pre-roll,
A2 forced mid-roll, A3 viewer-chosen) and `ad_relevance_arm` the relevance condition. Survey items
keep their questionnaire ids: `int_1`–`int_7` perceived intrusiveness, `irr_1`–`irr_5` irritation,
`rel_1`–`rel_3` perceived fit, `ctrl_1`–`ctrl_3` perceived control, `iuipc_*` privacy concern,
`pk_1`–`pk_3` persuasion knowledge, `track_1`–`track_2` perceived tracking, `ad_att_*` and
`plat_att_*` attitudes.

`session_id` is a random token generated by the platform. The platform did not record Prolific IDs
or any other identifier, and free-text debrief comments have been removed.

Part of the event log was lost under server load in one recruitment wave (Section 3.7). For those
sessions, answers missing from the export are filled from the page-by-page survey events where
these arrived; `prepare.derive` reports how many.
